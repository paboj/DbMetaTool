# Domeny — baza testowa

*Przykładowa domena: zarządzanie zapasami spożywczymi, inspirowana Kitchen.Api.*

```sql
CREATE DOMAIN D_PRODUCT_NAME AS VARCHAR(100) NOT NULL;

CREATE DOMAIN D_AMOUNT AS DOUBLE PRECISION NOT NULL DEFAULT 0
  CHECK (VALUE >= 0);

CREATE DOMAIN D_UNIT_TYPE AS SMALLINT NOT NULL DEFAULT 0
  CHECK (VALUE BETWEEN 0 AND 3);

CREATE DOMAIN D_STORAGE_LOCATION AS SMALLINT NOT NULL DEFAULT 0
  CHECK (VALUE BETWEEN 0 AND 3);
```
